The Databases window reads JSON columns properly, and its columns can be widened.

- A JSON or JSONB value shows its one line with a `{ }` mark; click it to read the whole document, indented and selectable. Text that isn't JSON is shown as before.
- Drag the divider at a column's right edge in the header to widen or narrow it.
- Values stay inside their column: selecting a cell no longer draws its text over its neighbours.
