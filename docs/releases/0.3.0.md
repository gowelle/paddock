Paddock can now look inside the databases it runs.

- The menu gains a Databases row once a PostgreSQL or MySQL service is added. It opens a window on the service's databases, tables and columns, the first 50 rows of a table with each column's type and primary key, and a read-only SQL console (⌘↩).
- Search finds rows holding a text in any column, looked for in the database across the whole table, and a filter narrows the table list as you type.
- `paddock db list`, `tables`, `columns`, `rows` and `query` do the same in the terminal, with `--service`, `--search` and `--limit`.
- Nothing in it can write: a statement that could write is refused before PHP starts, and the query runs in a read-only transaction with a five-second limit. Creating a database is still `paddock service create-db`.
