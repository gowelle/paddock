Paddock can now work with your AI coding agent.

- `paddock mcp` is a Model Context Protocol server. An agent can ask Paddock for a site's address and PHP version, a service's ports and `.env` lines, the end of a log, and the mail your app just sent.
- It can make a few small changes for you: pin a site's PHP version, switch Xdebug, start or stop a service, create a database, restart a task you approved.
- It cannot approve a site's `paddock.json`, change what macOS trusts, remove anything, or read the keys Paddock generated. `--read-only` and `--no-logs` narrow it further.
- Set-up is one line in your agent's configuration: the command `paddock` with the argument `mcp`. The README has the details.
