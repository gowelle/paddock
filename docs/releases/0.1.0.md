The first release of Paddock: a local PHP and Laravel environment for Intel Macs.

## What's in it

- **Sites.** Any folder in a parked directory is served at `<folder>.test`, over trusted HTTPS when you ask for it.
- **PHP.** PHP 8.5 is built in; 8.4 installs without a download. Each site can use its own version. `php` and `composer` work in your terminal.
- **Xdebug.** One switch per PHP version; it starts only when a request asks for it.
- **Services.** PostgreSQL (with PostGIS), MySQL, Redis (Valkey), Meilisearch, a mail catcher and S3-compatible object storage, added from Settings or `paddock service`.
- **Mail, Logs and Dumps windows.** Read the mail your app sends, follow every log as it is written, and see `dump()` and `dd()` from every site.
- **Site tasks.** Queue workers, schedulers and other commands from a site's `paddock.json`, run once you approve them.
- **Updates.** Paddock checks for a newer version once a day and asks before installing.

## Installing

```sh
curl -fsSL https://raw.githubusercontent.com/gowelle/paddock/main/Scripts/install.sh | bash
```

Needs an Intel Mac with macOS 13 or later. Paddock is not signed with an Apple Developer ID; the README says how to install by hand.
